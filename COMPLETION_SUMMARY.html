✅ API Endpoints

Authentication: POST /api/auth/register - Register new user POST /api/auth/login - Login user Users (Protected): GET /api/users - Get all users GET /api/users/:id - Get user by ID POST /api/users - Create user PUT /api/users/:id - Update user DELETE /api/users/:id - Delete user PUT /api/users/:id/password - Change password Products: POST /api/products - Create product GET /api/products - Get all products GET /api/products/:id - Get product GET /api/products/search - Search products PUT /api/products/:id - Update product DELETE /api/products/:id - Delete product PATCH /api/products/:id/stock - Update stock
